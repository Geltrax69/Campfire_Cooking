# Content

Game data as JSON, produced in the Design Phase (see `docs/DESIGN_PROMPTS.md`) and loaded by the simulation.

| Folder | Contents |
|---|---|
| `world/` | locations, travel times, town state |
| `npcs/` | villagers |
| `economy/` | currency, prices, producers, shops, wages |
| `items/` | item types |
| `skills/` | skills |
| `recipes/` | cooking and crafting |
| `animals/` | species |
| `social/` | perception, rumors, reputation groups |
| `player/` | player start |

Conventions are in `docs/DESIGN_PROMPTS.md` ("Shared conventions"). Every file has `"version": 1`.
