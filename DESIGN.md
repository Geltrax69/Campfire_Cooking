# Living World Unity presentation

Preserve the approved Kenney low-poly visual world and immersive interface in README.md. The village is the main surface; UI occupies a quiet top status strip and a contextual shop panel. Use warm ivory text on deep brown surfaces with restrained leaf-green action emphasis. Touch controls remain comfortably inside safe areas. Shop stock and player inventory come only from bridge snapshots. Errors are visible and actionable. Season may be displayed as season; never label it weather.

The first slice is a shop interaction prototype. It must identify what is currently implemented and must not imply completion of movement, NPC navigation or the full village.
