# P4-04: Phase 4 acceptance (season-long animal simulation)

**Role:** Test & Scenario agent
**Branch:** task/P4-04-acceptance
**Depends on:** P4-01, P4-02, P4-03

## Goal
Prove Phase 4 works end-to-end: a season-long simulation where animal populations shift with winter, the player tames a chicken, a wolf livestock incident occurs, and all state survives save/load.

## Context
Phase 4 is "Animal ecosystem and taming". P4-01 built animal state. P4-02 built ecosystem dynamics. P4-03 built taming. This task:
1. Wires animal state into save/load persistence (format v4, or extend v3)
2. Runs a season-long acceptance simulation proving the systems work together
3. Produces a readable log

## Requirements
1. **Persistence wiring**: Extend the save format to include:
   - `AnimalStore` (all animals: ID, species, location, trust, health, owner, age)
   - Use the `Capture()`/`Restore()` APIs from P4-01.
   - Bump format version (3 → 4) and ensure v3/v2/v1 documents still load with animal defaults (empty store, or initial populations? Document the choice).
2. **Season-long acceptance scenario** (`SimulationTests/Scenarios/Phase4AnimalAcceptanceTests.cs`):
   - Set up: village with initial animal populations (from P4-01 factory).
   - Simulate 90 days (one season, autumn → winter):
     - Each day: run PredationSystem, BreedingSystem (if spring), WinterPressureSystem (if winter), EggProductionSystem.
     - Player tames a chicken: 7 days of hand-feeding → bonded.
     - Verify a wolf livestock incident occurs during winter (2-4 per winter).
   - Verify:
     - Chicken is bonded to player after 7 days.
     - Deer population decreases (wolf predation).
     - At least 1 livestock loss occurs in winter.
     - Egg production is seasonal (more in autumn than winter).
     - No exceptions, animal counts are non-negative.
   - The test must be deterministic (fixed seed).
3. **Readable log**: The acceptance test writes a human-readable log to `SimulationTests/Scenarios/Phase4_Acceptance_Log.md` showing:
   - Week-by-week: population counts per species, livestock losses, eggs produced.
   - Taming progress: day-by-day trust for the chicken.
   - Wolf incidents: when they happened, what was lost.
   - Final: population counts, bonded animals.
4. **Save/load round-trip**: Save at day 45, load, continue to day 90. Verify the final state matches an uninterrupted 90-day run (determinism).

## Tests required
- `NinetyDayAnimalAcceptance`: The full scenario above.
- `AnimalStateSaveLoadRoundTrip`: Save/load preserves all animals.
- `AnimalSaveFormatVersion`: Version 4 saves load; version 3 saves load with animal defaults.
