## Goal
Automate every Apple Test exit condition for both witness and no-witness seeds, and
produce one readable report that a human can follow as a village story.

## Context
P1-20a supplies the deterministic three-day harness. This task proves that the
approved outcomes emerge from general systems in both perception branches. See
`docs/ROADMAP.md` Phase 1 and `docs/design/ECONOMY.md` section 10.

## Requirements
1. Add end-to-end acceptance tests using one seed where Lida witnesses the theft and
   one seed where she does not. Keep the 50% perception rule; do not bypass it.
2. In both branches prove the theft, shortage (partial or failed purchase), Mira's
   six-missing-apples belief without an invented culprit, restock to 45, bounded
   price rise to 4, money conservation and same-seed determinism.
3. Witness branch: prove the theft belief travels through real conversations with a
   traceable Lida source chain, and Bram remains below the 70-point proof threshold.
4. No-witness branch: prove no NPC receives a theft-observed belief naming the player,
   no theft rumor is created, nobody suspects the player, and Bram does not act.
5. Expose only read-only outcome views needed by tests/reporting. Do not add direct
   outcome mutations or assertions against private implementation details.
6. Extend the text report only as needed so a non-programmer can follow Day 1 theft
   and count, Day 2 shortage, beliefs/rumor branch, Day 3 delivery/price, and guard
   conclusion. Preserve deterministic ordering and byte-identical output.
7. Print the witness report from the acceptance test with `TestContext.Progress` so
   it is available in test output for the human review gate.
8. Keep this task below about 500 changed lines; stop and report if a runtime API is missing.
