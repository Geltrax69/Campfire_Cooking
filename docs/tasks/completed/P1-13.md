# P1-13: Belief-aware NPC decisions

**Role:** Agents (NPC behaviour)
**Branch:** task/P1-13-belief-decisions
**Depends on:** P1-10, P1-11

## Goal
Allow the existing utility decision system to use only an NPC's own beliefs when
evaluating choices such as visiting a shop believed to lack an item.

## Context
An NPC who learned that a purchase failed may change plans; an NPC who did not
learn it must behave as before. World stock is not knowledge and cannot be read
through this integration.

## You may edit
- `Packages/com.geltrax.livingworld.simulation/Runtime/Agents/`
- `SimulationTests/Agents/`

## You must not edit
- Anything outside the folders above. If Knowledge needs a new API, stop and report it.

## Requirements
1. Extend caller-supplied decision context with a read-only view of beliefs for the deciding NPC.
2. Add a general, configurable utility adjustment or eligibility rule for relevant structured claims.
3. Never read shop inventory, event truth, or another NPC's beliefs from decision logic.
4. Absence of a belief preserves existing P1-10 behavior.
5. Stable ordering and seeded tie-breaking remain deterministic.
6. Do not invent production confidence thresholds or utility penalties; require caller-supplied tuning.

## Tests required
- A sufficiently confident own belief that a shop/item is unavailable changes the next choice.
- The same fact in another NPC's belief store does not affect this NPC.
- No belief, low-confidence belief under supplied threshold, and unrelated belief preserve behavior.
- Repeated runs with the same seed and inputs select the same intention.
