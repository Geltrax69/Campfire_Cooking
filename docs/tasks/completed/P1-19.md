# P1-19: Readable simulation truth report
**Role:** Test & Scenario (report-tool implementation)
**Branch:** task/P1-19-readable-log
**Depends on:** P1-03 (merged)

## Goal and context
A deterministic plain-text formatter turns real WorldEvent records into a log a
human can read. This tool reports truth, never claims NPCs know those facts.
Read AGENTS.md and startup docs; inspect the existing event model.

## You may edit
- SimulationTests/Tools/
No production runtime, docs, Content, project configuration, git writes or agents.

## Requirements
1. Implement a reusable SimulationLogWriter accepting TextWriter and events plus
   optional NPC/location/item display-name dictionaries. Fallback to canonical IDs
   and Player, never invent facts. Use one-based Day and HH:mm, invariant culture.
2. Format Purchase, PartialPurchase, FailedPurchase, Theft, StockCounted,
   Conversation, Departure, Arrival. Render only fields present in the event;
   no invented desired quantity, witness, thief, outcome or confidence.
3. Stable event order; read-only inputs, no mutation. Reject null/invalid parameters;
   names must not inject extra lines (normalise newline/control whitespace).
4. Write header explicitly identifying WORLD TRUTH, not NPC knowledge. A short
   summary counts actual event kinds and covered game-day range, no story scripting.
5. Add a runnable NUnit demonstration which uses real CommandSystem/TravelSystem
   and a tiny hand-built map/NPC, queues a concrete travel command, ticks through
   arrival, and prints the formatter output through TestContext.Progress. Clearly
   call this foundation demo, NOT the Apple Test or autonomous village.
6. Keep under ~400 lines including tests; no NuGet dependencies or Unity.

## Tests required
All event types and absent optional fields, deterministic culture-independent text,
display-name/fallback and newline safety, empty log, non-mutation, real command/travel
demo, summary counts. Full Debug/Release suite and exact focused demo command.

## Done when
Orchestrator reviews, runs formatter/demo, records evidence and checks CI.
