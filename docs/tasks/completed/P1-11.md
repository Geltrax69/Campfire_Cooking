# P1-11: Per-NPC beliefs with provenance
**Role:** Knowledge
**Branch:** task/P1-11-beliefs
**Depends on:** P1-03 (merged)

## Goal and context
An NPC stores structured claims, confidence, time and provenance without reading
world truth. Read AGENTS.md, startup docs and docs/design/KNOWLEDGE.md.

## You may edit
- Packages/com.geltrax.livingworld.simulation/Runtime/Knowledge/
- SimulationTests/Knowledge/
No other files, docs/config, Content, git writes or child agents.

## Requirements
1. C#9 / .NET Standard 2.1, tests first; no engine/dependencies. ~400 lines target.
2. Immutable typed BeliefClaim: kind (StockAvailable, StockMissing, TheftObserved,
   Presence), location, optional item, optional ActorId subject, optional quantity.
   Validate kind-specific fields: unknown thief stays null, never substitute Player.
   Distinct item/actor/quantity claims remain distinct; deterministic equality/order.
3. Immutable BeliefSource records Seen, ToldBy or Inferred, optional origin
   WorldEventId, and defensive immutable NpcId source chain. ToldBy requires a
   speaker; invalid/default IDs and repeated source-chain NPCs are rejected.
4. Belief is immutable claim/source/confidence(0..100)/learned-at. BeliefStore for
   one NPC supports explicit Set and filtered queries, stable deterministic order.
   Updating the same claim preserves one entry, rejects older learned times;
   confidence is explicitly supplied, never silently amplified from repetitions.
5. KnowledgeState registers NPC stores and enumerates by ID. WorldState.Knowledge
   via a NEW partial file in your owned folder (namespace Core for this seam).
   Existing WorldState files must not change. No NPC registration cross-dependency.
6. RetainedEventIds returns sorted distinct referenced IDs for safe log pruning.
   Empty knowledge remains empty even when truth log contains a theft. No perception,
   inference, rumor generation, memory decay or guard decisions yet.

## Tests required
Invalid values/source chains; defensive copies; per-NPC isolation; add/update/query;
backdated update atomicity; unobserved theft does not create knowledge; unknown actor
never identified; stable order and retained IDs. Full Debug/Release suites.

## Done when
Orchestrator reviews, reruns tests and validates CI before merge.
