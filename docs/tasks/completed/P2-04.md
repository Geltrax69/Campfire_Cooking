# P2-04: Attributed interaction memories (who-did-what, recalled)

**Status:** Completed

**Role:** Knowledge
**Branch:** task/P2-04-memories
**Depends on:** P2-02

## Goal
Relationship shifts leave attributed memories ("Ralf cheated me", "Bessa gave
me bread") that the involved NPC later recalls — and recalling nudges the
relationship again, so the past keeps shaping the present. This is the "memory
depth" half of Phase 2.

## Context
P2-02 shifts trust/affection and logs `RelationshipShift` events. P1-17 gave
memories importance and decay. Now connect them: significant shifts become
memories *about a specific actor*, and those memories feed back into the
relationship when recalled. Systems, not scripts — the same rule for every pair.

## Requirements
1. When `RelationshipDynamicsSystem` applies a shift with magnitude ≥ 2
   (document the threshold), also record a memory in the affected NPC's
   `MemoryStore`: claim names the actor and the kind
   (e.g. `WrongedBy(npc_tom_fenn)`, `GiftFrom(npc_bessa_marlowe)` —
   design the claim encoding, keep it consistent), importance scales with
   shift magnitude, origin event = the `RelationshipShift` event.
2. Recall reinforcement: when an NPC with such a memory perceives or
   considers the named actor (e.g. during perception of a new event involving
   them, or a daily reflection pass — your choice, document it), apply a
   small bounded nudge (±1) to trust/affection in the memory's direction,
   scaled by the memory's *current* (decayed) strength. A faded memory barely
   nudges; a fresh betrayal stings.
3. **No runaway feedback**: the nudge must not create a self-amplifying loop
   (reinforcement never creates a new attributed memory; clamp total
   recall-driven movement per memory, e.g. it can at most double the original
   shift — document the bound and prove it in a test).
4. Respects truth≠knowledge: only the NPCs involved (or told via rumor)
   hold the memory; never read world truth to decide who remembers.

## Tests required
- A witnessed theft creates a `WrongedBy` memory in the witness with the
  right actor, importance and origin event.
- Recall nudges trust further down while the memory is strong; barely moves
  it after the memory has decayed.
- No runaway: 30 days of recalls move trust at most the documented bound.
- Gift memory works symmetrically (affection).
- Full suite green, Debug + Release.
