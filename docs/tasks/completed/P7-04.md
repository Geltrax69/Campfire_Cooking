# P7-04: Phase 7 acceptance (multi-year generational simulation)

**Role:** Test & Scenario agent
**Branch:** task/P7-04-acceptance
**Depends on:** P7-01, P7-02, P7-03

## Goal
Prove Phase 7 works end-to-end: a 5-year simulation where generations turn over (births, deaths, inheritance), and all state survives save/load.

## Context
Phase 7 is "Reincarnation and generations". P7-01 built aging/death. P7-02 built families/births. P7-03 built inheritance. This task:
1. Wires generation state (AgingState, FamilyState, HouseholdRegistry, InheritanceState, NPC age/isDeceased/family fields) into save/load persistence (format v7, or extend v6)
2. Runs a 5-year acceptance simulation
3. Produces a readable log

## Requirements
1. **Persistence wiring**: Extend the save format to include:
   - `AgingState` (last aging day, initialized)
   - `FamilyState` (last family day, births so far)
   - `HouseholdRegistry` (all households + members)
   - `InheritanceState` (processed deceased set)
   - NPC fields: `Age`, `IsDeceased`, `MotherId`, `FatherId`, `PartnerId`, `ChildrenIds`, `HouseholdId`, `DesignatedHeirId`
   - Use Capture()/Restore() APIs where available; add them if missing.
   - Bump format version (6 → 7) and ensure v6/v5/.../v1 load with generation defaults.
2. **5-year acceptance scenario** (`SimulationTests/Scenarios/Phase7GenerationsAcceptanceTests.cs`):
   - Set up: village with initial NPCs (some elders, some adults, some children).
   - Simulate 5 years (5 × 360 = 1800 days):
     - Each day: run aging, family, inheritance systems.
     - Track: births, deaths, inheritances.
   - Verify:
     - At least 1 birth and 1 death occur (use a seed that triggers them, or set up elders).
     - Inheritance distributes wealth (money conserved).
     - No exceptions, no negative ages, no duplicate IDs.
   - Deterministic (fixed seed).
   - Note: 1800 days may be slow; if too slow, reduce to 3 years (1080 days) and document.
3. **Readable log**: Write to `SimulationTests/Scenarios/Phase7_Acceptance_Log.md`:
   - Year-by-year: births, deaths, population.
   - Inheritance: who died, who inherited, amounts.
   - Final: population, age distribution, households.
4. **Save/load round-trip**: Save at year 2, load, continue to year 5. Verify final state matches uninterrupted run.

## Tests required
- `FiveYearGenerationsAcceptance`: The full scenario.
- `GenerationStateSaveLoadRoundTrip`: Save/load preserves aging, families, inheritance.
- `GenerationSaveFormatVersion`: Version 7 loads; version 6 loads with generation defaults.
