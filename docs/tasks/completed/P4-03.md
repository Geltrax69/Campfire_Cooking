# P4-03: Taming through trust

**Role:** Agents (NPC behaviour) agent
**Branch:** task/P4-03-taming
**Depends on:** P4-01

## Goal
Implement taming as a relationship, not a button: trust builds 0-100 through repeated calm interactions (one meaningful gain per day), takes 5 days for a brambleback and two full seasons for a wolf pup, and breaks through cruelty or neglect.

## Context
Phase 4 is "Animal ecosystem and taming". P4-01 built animal state. This task implements the taming mechanics from docs/design/ANIMALS.md section on taming and docs/design/SKILLS.md section 3 (Taming skill).

## Requirements
1. **TamingInteraction**: Types of interaction with trust effects:
   - Chicken: +8/day hand-feeding, +5 gentle handling, -20 rough handling, -30 chased by dogs. Bonded at 60+ (~7 days).
   - Pig (piglet): +6/day feeding, +10 scratching, -25 struck, -40 starved. Bonded at 70+ (~12 days). Wild boars can NEVER be tamed.
   - Deer (fawn only): +4/day winter feeding, +2 calm presence, -30 chase/noise. Bonded at 80+ (~20-30 days). Stags can NEVER be tamed.
   - Wolf (orphaned pup only): +5/day feeding meat, +5 play/training, +8 calm strength, -50 struck, instant break if starved. Bonded at 85+ (~60 days). **Requires council approval** (see below).
   - Brambleback: +?/day (design says 5 days to bond; use +20/day porridge). Bonded at 60+.
2. **One meaningful gain per day**: Each animal can gain trust from only one interaction per game day. Additional interactions that day have no effect (or a tiny +1). Track `LastInteractionDay`.
3. **TamingSystem** (or static `Taming.Interact`):
   - `Interact(animal, actor, interactionType, day, rng)`: Applies trust change, updates LastInteractionDay, returns the trust delta.
   - Validates: cannot tame a wild boar or stag (throws or returns rejection).
   - If trust reaches the bond threshold: set `BondedOwner = actor`, record a truth event (Bonded).
   - If trust drops below 30 (wolf) or 40 (pig): the animal leaves/reverts (BondedOwner = null, trust reset to 10).
   - Cruelty (struck): wolf trust -50; if wolf trust breaks through cruelty, record a special event (may turn — future work).
4. **Council approval for wolves**: Before a wolf pup can be tamed (trust > 0), the actor must have council approval.
   - For now: approval is a boolean on the actor (or a relationship flag). If not approved, `Interact` with a wolf returns rejection.
   - Document: real council voting is Phase 5 (town development) work.
5. **Taming skill integration**: The actor's `skill_taming` level affects trust gains:
   - Level 1: base rate (as above)
   - Level 2: ×1.5 trust gain
   - Level 3: ×2 trust gain
   - (Per SKILLS.md: "Trust gain ×1.5" at level 2, "×2" at level 3)
6. **Bonded services**: When an animal is bonded, it provides a service (record as truth; actual mechanics are future work):
   - Chicken: comes when called, lays in chosen nest box.
   - Pig: follows, finds mushrooms in autumn.
   - Deer: carries light packs (10kg), alarm-snorts at wolves.
   - Wolf: guards home, hunts alongside, tracks by scent.
   - Brambleback: fewer ticks on livestock (healthier chickens/pigs).
   - For now: just record the bond and the service type; P4-04 or later can implement the effects.

## Tests required
- `ChickenBondsInSevenDays`: 7 days of hand-feeding → trust >= 60, bonded.
- `CrueltyBreaksTrust`: Strike a bonded pig → trust drops significantly; may unbond.
- `WolfPupTakesSixtyDays`: 60 days of feeding/training → trust >= 85 (with approval).
- `WolfNeedsCouncilApproval`: Interact with wolf without approval → rejected.
- `WildBoarCannotBeTamed`: Interact with boar → rejected.
- `OneGainPerDay`: Two interactions in one day → only first counts (full gain).
- `TamingSkillMultipliesGains`: Level 3 tamer gains trust 2x faster than level 1.
