# P7-03: Inheritance

**Role:** Agents + Economy agent
**Branch:** task/P7-03-inheritance
**Depends on:** P7-02

## Goal
Implement inheritance: when an NPC dies, their money and items pass to heirs (spouse → children → village fund). Money is conserved.

## Context
Phase 7 is "Reincarnation and generations". P7-01 built aging/death. P7-02 built families. This task ensures wealth doesn't vanish when NPCs die.

## Requirements
1. **Heir priority**: When an NPC dies:
   1. Spouse/partner (if alive)
   2. Children (eldest first, split equally if multiple)
   3. Parents (if alive)
   4. Village fund (if no heirs)
2. **InheritanceSystem** (or static `Inheritance.Distribute`):
   - Takes the deceased NPC's wallet (money) and inventory (items).
   - Transfers to heirs per priority.
   - If multiple children: split money equally (integer division, remainder to eldest); items go to eldest (or split by value; document the choice).
   - Record truth events (Inheritance) for each transfer.
   - Money must be conserved: total money before = total money after.
3. **Wills** (simple): An NPC can designate a non-standard heir (e.g., "leave my tools to my apprentice").
   - For now: a simple `DesignatedHeirId` (nullable) on NpcState. If set, that NPC gets everything (overrides priority).
   - Document as simplification (real wills are more complex).
4. **Orphans**: If children inherit but are under 15, their inheritance is held by the household (or a guardian).
   - For simplicity: the eldest adult in the household holds it; document.
5. **Village fund**: If no heirs, money goes to the community fund (from P2-09 MoneySinks).
   - Items go to the village (or are sold; document the choice).
6. **Deterministic**: No RNG needed (priority is deterministic).

## Tests required
- `SpouseInheritsFirst`: Married NPC dies; verify spouse gets everything.
- `ChildrenSplitEqually`: NPC with 3 children dies; verify money split equally.
- `NoHeirsGoesToFund`: NPC with no family dies; verify village fund receives money.
- `MoneyConserved`: Total money in world is same before and after inheritance.
- `DesignatedHeirOverrides`: NPC with will designating a friend; verify friend inherits.
