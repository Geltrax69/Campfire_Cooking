# P1-21e: Save full world state to versioned JSON

**Status:** Completed

**Role:** Persistence
**Branch:** task/P1-21e-save
**Depends on:** P1-21d (world state must be complete first)

## Goal
Serialize the entire `WorldState` to a human-readable, versioned JSON document.
This is the save half of P1-21; P1-21f builds the loader and the determinism proof.

## Context
P1-21a/b/c added validated capture/restore contracts (event log + command queue,
`NpcState`, memories + perception cursor). P1-21d brought all mutable state under
`WorldState`. Now persist it. Save format decision (fixed): JSON, per AGENTS.md.

## You may edit
- `Packages/com.geltrax.livingworld.simulation/Runtime/Persistence/` (create)
- `SimulationTests/Persistence/` (create)
- Minimal internal serialization hooks on command types ONLY if needed
  (`Runtime/Core/Commands/`, `Runtime/Economy/TheftCommand.cs`) — keep them
  tiny, internal, and report each one. Anything bigger: stop and report.

## You must not edit
- Anything else. `Content/` is read-only (definitions are saved by ID and
  reloaded from approved data at load time — never duplicated into the save).

## Requirements
1. `WorldSaver` (name your choice): `WorldState` → JSON string via
   `System.Text.Json` (in-box for .NET 8 and Unity 6; no new packages).
2. The document starts with a **format version** (`"formatVersion": 1`) and a
   section per state area: clock, RNG state, event log (retained events +
   high-water marks from `CaptureState`), pending commands (type discriminator
   + payload), NPCs (definition ID + exact need sixtieths + sleeping flag +
   intention + belongings), beliefs, memories (exact records incl. strength),
   perception cursor, shops (stock + prices), production / restock /
   price-adjustment states, reputation standings, travel state.
3. Immutable definitions (NPC definitions, item catalog, locations, schedules)
   are referenced by ID only.
4. Saving is deterministic: saving the same world twice yields byte-identical
   JSON (sorted keys / deterministic ordering — no unordered iteration).
5. Document the schema briefly (a `SCHEMA.md` in the Persistence folder or a
   section in the test file) so the P1-21f loader agent can build against it.

## Tests required
- Save output parses as JSON and contains every section from requirement 2.
- `formatVersion` is present and == 1.
- Spot values match live world state (clock, an NPC's exact need sixtieths, a
  shop's stock, RNG state).
- Save twice → byte-identical output.
- Full suite still green, Debug + Release.
