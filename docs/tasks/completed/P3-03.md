# P3-03: Cooking effects on the world

**Role:** Agents + Economy agent
**Branch:** task/P3-03-cooking-effects
**Depends on:** P3-02

## Goal
Wire cooked-food quality into the world: meal quality affects NPC happiness and health; a skilled cook raises tavern popularity; ingredient demand shifts prices; better cooks waste less.

## Context
Phase 3 is "Skills, crafting and cooking". P3-01 built skill state. P3-02 built recipe execution. This task connects cooking to the living world systems per docs/design/SKILLS.md section 2 ("Systems touched").

## Requirements
1. **Meal quality → happiness**: When an NPC eats a cooked meal with quality Q:
   - Happiness delta = `(Q - 50) / 25` (rounded to int, can be negative). Quality 75 → +1, quality 100 → +2, quality 25 → -1.
   - This is a small daily effect that compounds (per WORLD.md).
   - Record as truth event (meal eaten with quality).
2. **Meal quality → health**: When an NPC eats a cooked meal with quality Q:
   - If Q >= 70: small health recovery bonus (e.g., +1 health, or faster recovery from illness - use whatever health system exists; if none, document as future work and skip).
   - If Q <= 30: small health penalty (bad food can make you sick).
3. **Tavern popularity**: Track a "tavern popularity" score (0-100, starts at 50).
   - When a cook with skill level L cooks at the tavern (loc_tavern), popularity += (L - 2) (so level 3+ raises it, level 1 lowers it slightly).
   - Popularity affects traveler behavior: higher popularity → travelers stay longer (add 1 night per 20 popularity above 50) → more ale/bed sales.
   - Popularity decays slowly toward 50 when no skilled cooking happens (people forget).
4. **Ingredient demand → prices**: When a recipe is cooked, increase demand for its inputs:
   - Track ingredient demand counters (per item, decays daily).
   - When demand is high, the price system should nudge prices up (use the existing PriceAdjustmentSystem if available; if not, document the hook point).
   - Specifically: apple pie cooking should visibly raise apple demand (per the recipe note: "visibly raises apple demand").
5. **Waste reduction**: At cooking skill level 2+, ingredient waste is halved.
   - For simplicity: when a level 2+ cook succeeds at a recipe, there is a 50% chance (seeded RNG) to refund 1 unit of a random input (representing "wasted less").
   - Document this simplification.
6. **Relationships**: Feeding someone is a social act.
   - When an NPC is given a cooked meal (not just eating their own), relationship trust += 1 (if quality >= 60) or += 2 (if quality >= 80).
   - This uses the P2-03 relationship system.

## Tests required
- `HighQualityMealRaisesHappinessMore`: NPC eats quality-80 stew → happiness +1 or +2; eats quality-50 stew → happiness +0.
- `TavernPopularityRisesWithSkilledCook`: Level 4 cook works at tavern → popularity increases; level 1 cook → popularity decreases or stays.
- `ApplePieRaisesAppleDemand`: Cooking apple pies increases apple demand counter; price nudge is triggered (or hook is called).
- `Level2CookWastesLess`: Over 100 trials, level 2+ cook gets waste refund ~50% of the time; level 1 never does.
- `FeedingRaisesTrust`: Giving a quality-80 meal to an NPC raises trust.
