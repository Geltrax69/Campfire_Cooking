# P8-02: Template phrasing (deterministic mock AI from fact sheets)

**Role:** Knowledge agent
**Branch:** task/P8-02-phrasing
**Depends on:** P8-01

## Goal
Turn a `FactSheet` into natural-sounding speech using deterministic templates.
This is the simulation-side stand-in for the future AI model: it phrases facts,
never invents them, never changes state.

## Context
P8-01 built the FactSheet (only NPC-known facts). Per docs/ARCHITECTURE.md §12:
"Until then, dialogue uses templates filled from the same fact sheet." An AI
model may later implement the same contract — so define a clean `IPhrasingEngine`
interface that the template engine implements and a future AI adapter could too.

The user forbids paid AI services and Unity work. This task is pure simulation:
deterministic C# templates only.

## Requirements
1. **`IPhrasingEngine` interface** (`Runtime/Knowledge/IPhrasingEngine.cs`):
   - `string Phrase(FactSheet sheet, DialogueIntent intent)` — pure function.
   - Document the contract: output must phrase only facts present in the sheet;
     must not add facts; must not change state; must be deterministic for the
     same (sheet, intent).
2. **`TemplatePhrasingEngine`** (`Runtime/Knowledge/TemplatePhrasingEngine.cs`):
   - Implements `IPhrasingEngine` with hand-written templates.
   - `DialogueIntent`: greeting, farewell, smalltalk, ask-about-player
     (what they think of the player), share-news (one known news item),
     ask-about-family.
   - Templates vary by `MoodBand` (a miserable NPC greets differently than a
     happy one) and by belief `SourceKind` (seen vs told vs inferred hedges
     differently: "I saw…", "I heard…", "I reckon…").
   - Seeded variation: the engine takes a seed; template choice among
     same-intent variants uses a seeded RNG draw — but **same (sheet, intent,
     seed) → same output**, always. Document that the seed is part of the input.
   - Must never emit a fact not in the sheet. Templates reference sheet fields
     only.
3. **No-fact-invention test**: for a fixed set of sheets × intents × seeds,
   assert every proper noun / number in the output appears in the sheet
   (or is a generic template word from an allowlist). This is the key safety test.
4. **Determinism test**: same (sheet, intent, seed) → byte-identical output;
   different seeds may vary wording but never facts.
5. **No-state-change test**: phrasing never mutates world state (digest check).

## Tests required
- `PhrasingIsDeterministicForSameInputs`
- `PhrasingVariesWithSeedButNotFacts`
- `PhrasingNeverInventsFacts` (the key test)
- `PhrasingReflectsMoodBand`
- `PhrasingHedgesBySourceKind`
- `PhrasingDoesNotMutateState`
- `TemplateEngineImplementsContract`
