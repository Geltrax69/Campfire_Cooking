# P8-01: FactSheet builder (dialogue reads NPC knowledge, never truth)

**Role:** Knowledge agent
**Branch:** task/P8-01-factsheet
**Depends on:** P7-04

## Goal
Build a `FactSheet` for an NPC: everything dialogue is allowed to phrase, drawn
only from what that NPC knows (their beliefs, memories, mood), never from world
truth they don't have access to.

## Context
Phase 8 is "AI dialogue from fact sheets (never changes game state)". The approved
design (docs/ARCHITECTURE.md §12) says: when the player talks to an NPC, the game
builds a **fact sheet** from simulation data — who the NPC is, their mood, what
they believe and remember about the player, recent local news they know. An AI
model may later turn that into natural speech, but the fact sheet is pure
simulation and must contain only facts the NPC actually knows.

The simulation has a rich Knowledge layer: `BeliefStore` (per-NPC beliefs with
confidence), `MemorySystem` (attributed memories), `NewsStore` (arrived news per
village), `NpcState.Mood` (0–100). Use these as sources. Do NOT read world truth
directly — e.g., if an NPC doesn't believe the player stole apples, the fact
sheet must not contain the theft.

## Requirements
1. **FactSheet type** (`Runtime/Knowledge/FactSheet.cs`):
   - Identity: NPC id, name, role/occupation (from Content), age/life stage.
   - Mood: 0–100 with a qualitative band (e.g., miserable/low/neutral/content/happy).
   - Beliefs about the player: each belief claim the NPC holds about the player,
     with confidence. Only beliefs the NPC actually holds.
   - Memories about the player: recent attributed memories involving the player
     (bounded, e.g., last 5, ordinal by recency).
   - Known news: recent arrived news the NPC's village knows (bounded, e.g., last 3).
   - Household/family context the NPC would know (their own household members).
   - The fact sheet must be a plain data object — no behavior, no RNG.
2. **FactSheetBuilder** (`Runtime/Knowledge/FactSheetBuilder.cs`):
   - `Build(WorldState state, NpcId npc)` → FactSheet.
   - Reads only from knowledge stores (beliefs, memories, news, mood).
   - Deterministic: same state → same sheet (ordinal iteration, no RNG).
   - Never throws on missing data; degrades gracefully (empty lists, neutral mood).
3. **Knowledge-vs-truth separation**:
   - Add a test proving the sheet excludes a truth the NPC doesn't know:
     set up a world event the NPC has no belief/memory of; assert the fact
     sheet doesn't mention it.
   - Add a test proving the sheet includes a belief the NPC holds even if it's
     false (dialogue phrases beliefs, not truth).
4. **No state mutation**: building a fact sheet must not change any world state.
   Test: capture a save digest before/after building sheets for all NPCs.
