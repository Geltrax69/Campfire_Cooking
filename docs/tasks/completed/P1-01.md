# P1-01: Deterministic simulation primitives

**Role:** Core Simulation (two independent subfolders)
**Branch:** task/P1-01-core-primitives
**Depends on:** P0-01 (.NET 8.0.425 installed and test project restored locally)

## Goal
Provide strongly typed content IDs, integer game time, and a deterministic RNG
whose saved state resumes the exact sequence. No Unity or game balancing changes.

## Context
Read AGENTS.md and its required documents. Follow ARCHITECTURE sections 2–3.
Content IDs are strings such as npc_mira_holt, loc_apple_stall and item_apple.

## Requirements
1. C# 9, engine independent. Write tests first, then implementation.
2. Primitives: readonly value types NpcId, LocationId, ItemTypeId with string Value,
   IsValid, ordinal equality/comparison, stable hash and ToString; reject null/empty/
   whitespace values. No implicit conversions. default IDs are invalid but safe
   to compare/hash/print; future world entry points must reject them.
3. GameTime(long totalMinutes) rejects negatives; TotalMinutes, Day (one-based),
   Hour, Minute; Advance(long minutes) returns a new value, rejects negatives and
   checks overflow. A day is 1440 minutes. Equality and ordering by TotalMinutes.
4. SimRng(ulong seed) uses a documented small deterministic algorithm (SplitMix64)
   with unchecked arithmetic, ulong State, static FromState(ulong), NextUInt64(),
   and unbiased NextInt(int exclusiveMax), rejecting nonpositive bounds.
   All ulong seeds/states including zero are valid. No System.Random.
5. Stay under roughly 500 added lines for this task, including tests; avoid new
   generic frameworks or unrelated types. Public types have summary comments.

## Tests required
- IDs: equal/different/cross-type IDs, ordinal sort, invalid input and defaults.
- Time: minute/hour/day boundaries, advance, ordering, negative and overflow.
- RNG: known reference vectors, same seed, save/resume, zero seed, bounds and
  invalid bounds; no flaky distribution tests.
- Run: PATH="$HOME/.dotnet:$PATH" dotnet test SimulationTests.
