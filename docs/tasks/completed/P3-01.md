# P3-01: Skill state and progression

**Role:** Agents (NPC behaviour) agent
**Branch:** task/P3-01-skill-state
**Depends on:** P2-12

## Goal
Implement the skill system from docs/design/SKILLS.md: SkillState with levels 1-5, practice points, thresholds, daily cap, teaching bonus, and quality bonus. Both NPCs and the player have skill stores.

## Context
Phase 3 is "Skills, crafting and cooking". The skill system is the foundation: one system for all skills (cooking, taming, swordsmanship, plus the 5 absurd design-only skills). Levels are earned only through practice and teaching, never XP-from-killing. This task builds the state and progression rules; P3-02 will use it for recipe execution.

## Requirements
1. **SkillState class**: 
   - Skill ID (SkillId, e.g., `skill_cooking`)
   - Level (1-5, or 0 for unlearned)
   - Practice points (cumulative integer)
   - Daily points accrued (resets each game day)
   - Last practice day (to reset daily cap)
2. **Level thresholds** (cumulative points):
   - Level 1: 0 points (starting level)
   - Level 2: 100 points
   - Level 3: 300 points
   - Level 4: 700 points
   - Level 5: 1500 points
   - Level 0 → 1: 20 points (dabbling)
3. **Practice(points, isTaught, day, rng)**:
   - Base gain: `points` (typically 1 per meaningful use)
   - If `isTaught` by someone with higher level: ×2
   - Daily cap: max 20 points per game day (excess is lost)
   - Returns actual points gained
   - Triggers level-up when thresholds are crossed
4. **Quality bonus**: Level 1: +0, Level 2: +1, Level 3: +2, Level 4: +3, Level 5: +4. Level 0: +0.
5. **SkillStore**: Per-actor (NPC or player) collection of SkillStates. Methods: `Get(skillId)`, `Practice(skillId, points, isTaught, day, rng)`, `GetLevel(skillId)`, `GetQualityBonus(skillId)`.
6. **WorldState integration**: Add `SkillStore` to NPC state and player state. Must be save/load-compatible (add to Persistence in a way that P3-04 or a follow-up can wire; at minimum, the state must be capturable/restorable via public methods).
7. **No decay**: Skills never decrease (per design: "a skill learned is kept").
8. **Deterministic**: Use the world's seeded RNG for any randomness (though practice itself is deterministic; RNG is for future use).

## Tests required
- `PracticeGrantsPointsAndLevelsUp`: Practice 100 points → level 2; 300 total → level 3, etc.
- `DailyCapEnforced`: Practice 30 points in one day → only 20 accrued; next day can gain more.
- `TeachingDoublesGains`: Practice 10 points with isTaught=true → 20 points gained (subject to cap).
- `QualityBonusByLevel`: Level 1 → +0, Level 3 → +2, Level 5 → +4.
- `DabblingUnlocksLevel1`: Level 0 + 20 points → level 1.
- `NoDecay`: (Implicit - no API to decrease; document in test that points never decrease.)
