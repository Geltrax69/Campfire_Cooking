# P1-16b: Deterministic item production

**Role:** Economy
**Branch:** task/P1-16b-production
**Depends on:** P1-07, P1-10, P1-16a

## Goal
Add general, caller-configured item production whose completion state can be saved
and restored without duplicating goods.

## Context
The farm must create real stock before a delivery can move it to the stall.

## You may edit
- `Packages/com.geltrax.livingworld.simulation/Runtime/Economy/`
- `SimulationTests/Economy/`

## You must not edit
- Anything outside the folders above. Use the P1-16a Core event vocabulary as-is.

## Requirements
1. Add validated, immutable caller-supplied production configurations; no hard-coded apple/farm values.
2. Production adds the configured quantity at the configured eligible time exactly once and records `Produced` truth.
3. Store completion markers in caller-owned, deterministically ordered state that can be reconstructed for persistence.
4. Recreating the system with restored state must not duplicate goods or events.
5. Process configurations in stable ordinal order and remain deterministic, C# 9 compatible, and Unity-free.

## Tests required
- Production happens once at its configured time and not on repeated ticks.
- Multiple eligible configurations process in stable order.
- Recreating with restored completion state does not duplicate production.
