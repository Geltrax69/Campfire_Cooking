**Status:** Completed

**Role:** Agents (NPC behaviour)
**Branch:** task/P1-21b-agent-restore
**Depends on:** P1-20

## Goal
Allow Persistence to reconstruct mutable NPC state exactly, including fractional need
progress, sleeping state and current intention, while reusing approved definitions.

## Context
P1-21 reloads immutable NPC definitions from approved Content, then restores mutable
state. Whole-point constructors currently lose need sixtieth remainders.

## Requirements
1. Add the smallest validated restore path for `NpcState` from an existing definition,
   exact `NeedState`, sleeping flag and optional current intention.
2. Preserve need sixtieths exactly; do not round through the public whole-point values.
3. Reject inconsistent or invalid restored state rather than silently normalizing it.
4. Keep the normal new-game constructor and decision behavior unchanged.
5. Keep restore-only APIs assembly-internal where practical; do not add JSON here.

## Tests required
- Fractional needs, sleeping state and intention round trip exactly.
- Awake/no-intention state round trips and advances identically after restore.
- Invalid contradictory state is rejected without mutating the source.
