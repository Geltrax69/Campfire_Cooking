# P1-12: Deterministic perception of truth events

**Role:** Knowledge
**Branch:** task/P1-12-perception
**Depends on:** P1-10, P1-11

## Goal
Turn eligible world events into per-NPC observations and beliefs using explicit,
seeded notice rules while preserving the separation between truth and knowledge.

## Context
The Apple Test needs nearby awake witnesses to possibly notice a theft while
sleeping, absent, or travelling NPCs cannot. Perception may only expose facts
present in the observed event.

## You may edit
- `Packages/com.geltrax.livingworld.simulation/Runtime/Knowledge/`
- `SimulationTests/Knowledge/`

## You must not edit
- Anything outside the folders above. If another area's API is insufficient, stop and report it.

## Requirements
1. Add explicit perception tuning/context interfaces; do not invent production notice chances.
2. Process new perceivable events once in stable event order and candidate NPCs in ordinal ID order.
3. Require the context to establish presence at the event location and awake status before any notice roll.
4. Use only `WorldState.Rng` for probabilistic notice; identical seed and inputs must match exactly.
5. Store an observation-derived belief with source kind, confidence, learned time, and referenced event ID.
6. Never infer an unidentified thief, query hidden world state, or give knowledge to ineligible NPCs.
7. Avoid duplicate observations when later ticks contain no new event.

## Tests required
- Nearby awake NPC can notice under deterministic tuning; asleep, remote, and travelling NPCs cannot.
- Fixed seeds reproduce noticed/not-noticed outcomes and processing order.
- Re-ticking does not duplicate beliefs or consume rolls for already processed events.
- An event without actor identity cannot create a belief naming an actor.
