# P1-16a: Economy event vocabulary

**Role:** Core Simulation
**Branch:** task/P1-16a-economy-events
**Depends on:** P1-03

## Goal
Extend the closed world-event vocabulary with the general truth facts required by
P1-16: restock ordered, item produced, stock delivered and price changed.

## Context
Economy cannot correctly log P1-16 through the existing purchase/theft/count event
kinds. This task defines only event kinds and validation support, not economy rules.

## You may edit
- `Packages/com.geltrax.livingworld.simulation/Runtime/Core/Events/`
- `SimulationTests/Core/Events/`

## You must not edit
- Anything outside the folders above.

## Requirements
1. Add general event kinds for `RestockOrdered`, `Produced`, `Restocked`, and `PriceChanged`.
2. Preserve all existing enum values and event validation behavior.
3. Do not add tuning, business logic, content values, or Economy dependencies.
4. Keep C# 9 compatibility and no Unity references.

## Tests required
- EventLog accepts each new kind and returns it in append order with supplied facts.
- Out-of-range enum values remain rejected.
