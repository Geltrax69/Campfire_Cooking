# P7-02: Families

**Role:** Agents (NPC behaviour) agent
**Branch:** task/P7-02-families
**Depends on:** P7-01

## Goal
Implement families: parent/child links, households, and births. Children are born, grow up in households, and inherit family ties.

## Context
Phase 7 is "Reincarnation and generations". P7-01 built aging. This task adds family structure.

- SimulationTests/Agents/ (new test files)

## You must not edit

## Requirements
1. **Parent/child links**: Each NPC can have:
   - `MotherId` (nullable NpcId), `FatherId` (nullable NpcId)
   - `ChildrenIds` (list of NpcId)
   - These are set at birth and never change.
2. **Households**: A household is a group of NPCs living together.
   - `HouseholdId` (strongly-typed), `MemberIds` (list), `HomeLocation`
   - Children belong to their parents' household.
   - When a child becomes an adult (age 15), they may form a new household (or stay; use seeded RNG, 50% chance).
3. **Births**: When two adult NPCs are married/partnered (for now: use a simple "partner" link, or just pick two adults in the same household), they may have a child.
   - Birth chance: 10% per year per eligible couple (seeded RNG).
   - New NPC: age 0, parents set, household = parents' household, name generated (e.g., "Child of [Mother]").
   - Record a truth event (Birth).
   - For simplicity: only opposite-gender couples; document as simplification.
4. **FamilySystem** (IWorldSystem): Runs yearly; checks for births; handles household formation when children become adults.
5. **Initial families**: Use Content NPC data to set up initial parent/child links (e.g., Tansy is Garrick's daughter - this is already in the design).
   - If Content doesn't have family data, create a simple setup: assign children to adults in the same home location.
   - Document the approach.
6. **Deterministic**: All RNG uses seeded RNG.

## Tests required
- `ParentChildLinks`: Create parent and child; verify links are bidirectional.
- `BirthsHappen`: Eligible couple; run a year; verify child may be born (use seed that triggers it).
- `ChildrenInheritHousehold`: Child born; verify household matches parents'.
- `AdultChildrenMayLeave`: Child turns 15; verify they may form a new household.
