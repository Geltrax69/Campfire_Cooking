# P2-03: Relationships shape behavior (rumor trust, friend prices, social choice)

**Role:** Knowledge + Agents (Economy touch for pricing — single agent, sequential)
**Branch:** task/P2-03-rel-behavior
**Depends on:** P2-02, P2-04, P2-08 (Economy folder)

## Goal
Relationships stop being numbers and start driving behavior: whom NPCs
believe, what they charge their friends, and whose company they seek.

## Context
P2-01–P2-04 built directed trust/affection, rule-driven shifts, and
attributed memories. Now the loop closes: relationship values feed back into
decisions. Design anchors: "Bessa never charges Ralf full price"
(ECONOMY.md); rumors are the village's nervous system (D-09).

## Requirements
1. **Rumor trust filter** (Knowledge): when an NPC receives a rumor, the
   confidence they adopt it with scales with their trust in the speaker.
   Document the rule (e.g. adopted confidence = rumor confidence ×
   trust/50, clamped; below some trust floor the rumor is rejected
   outright). A warning from a trusted friend lands; the same story from a
   distrusted stranger dies.
2. **Believed rumors leave memories** (Knowledge, closes the P2-04
   follow-up): a rumor about a wrongdoing that is adopted with high
   confidence creates a `WrongedBy` attributed memory in the listener via
   the P2-04 mechanism (second-hand, so lower importance than witnessing —
   document the factor). Low-confidence rumors leave no memory.
3. **Friend prices** (Economy): shopkeepers give friends a small, bounded
   discount. Document the rule (e.g. discount up to 20%, scaling with
   trust+affection; never below cost). Bessa→Ralf must show it in a test.
   NPC shopkeepers use their *own* relationship values, not world truth.
4. **Social choice** (Agents): when an NPC chooses conversation company
   (tavern evenings, rest breaks), add an affection-based utility bonus so
   friends seek each other out. Document the weight. Never a hard script —
   a lonely NPC with no friends still talks to whoever is there.

## Tests required
- Trusted speaker's rumor adopted at high confidence; distrusted
  speaker's same rumor rejected/discounted.
- Believed wrongdoing rumor → `WrongedBy` memory in listener (lower
  importance than witnessed); disbelieved rumor → no memory.
- Friend discount: high-trust customer pays less than a stranger for the
  same good; discount bounded (never below cost, never above the cap).
- Social: given a choice, an NPC joins the high-affection NPC's table
  more often than chance (statistical test with fixed seed).
