# P8-04: Phase 8 acceptance (dialogue across the village)

**Role:** Test & Scenario agent
**Branch:** task/P8-04-acceptance
**Depends on:** P8-03

## Goal
Prove Phase 8 works end-to-end: build fact sheets and hold dialogue sessions
with multiple NPCs across a living village, produce a readable log, and verify
determinism and save/load compatibility.

## Context
Phase 8 is "AI dialogue from fact sheets (never changes game state)". P8-01
built the FactSheet, P8-02 the template phrasing engine, P8-03 the
DialogueSession contract. This task exercises all three against a real village:
NPCs with different moods, beliefs, memories, and known news — and shows what
each one says.

Dialogue is derived on demand from persisted knowledge state (P8-01), so no new
save-format work is expected — but verify that a save/load round-trip doesn't
change what NPCs say.

## Requirements
1. **Village dialogue acceptance** (`SimulationTests/Scenarios/Phase8DialogueAcceptanceTests.cs`):
   - Set up: a small village (or reuse an existing scenario helper) with several
     NPCs; give them distinct moods (set Happiness), distinct beliefs about the
     player (seen/told/inferred), and distinct known news (arrive 2–3 news items).
   - For each NPC: build a fact sheet, open a DialogueSession, run all 6 intents.
   - Verify:
     - Every utterance is non-empty.
     - Same seed → byte-identical utterances (determinism).
     - World digest unchanged after all sessions.
     - NPCs with different moods/beliefs produce different utterances
       (dialogue reflects knowledge).
2. **Save/load round-trip**: save the village, load it, rebuild sheets and
   sessions, verify utterances are identical to pre-save.
3. **Readable log**: Write to `SimulationTests/Scenarios/Phase8_Acceptance_Log.md`:
   - For each NPC: name, role, mood band, and one sample utterance per intent
     (or a curated subset — greeting, ask-about-player, share-news).
   - A short section demonstrating the knowledge/truth split: an NPC with a
     false belief says the false thing; an NPC who doesn't know a truth doesn't
     mention it.
   - Determinism and save/load results.
4. **No Unity, no AI services**: pure simulation; document that the template
   engine stands in for the future AI adapter behind `IPhrasingEngine`.
