# P2-01: Relationship state (directed trust/affection)

**Role:** Knowledge
**Branch:** task/P2-01-relationships
**Depends on:** P1-21

## Goal
Directed trust/affection pairs load from `Content/npcs/npcs.json` into
`WorldState`, so every NPC pair's relationship is world truth the simulation
can read and P2-02 can change.

## Context
`Content/npcs/npcs.json` already holds per-NPC `relationships` lists
(`with`, `trust`, `affection`, `reason`, 0–100). They are currently
design-time data only — nothing in the simulation reads them. Relationships
are DIRECTED (Mira→Ralf trust 60 need not equal Ralf→Mira). This task makes
them live state; dynamics (P2-02) and behavior (P2-03) build on it.

## You may edit
- `Packages/com.geltrax.livingworld.simulation/Runtime/Knowledge/` (new registry + `WorldState` partial)
- `SimulationTests/Knowledge/`

## You must not edit
- Anything else. `Content/` is read-only.

## Requirements
1. New `RelationshipRegistry` (name your choice) owned by `WorldState`
   (e.g. `WorldState.Relationships` or inside `KnowledgeState` — justify):
   directed pairs keyed by (from, to), values trust/affection 0–100 + reason.
2. Loader reads the `relationships` arrays at world build (follow the
   `NpcContentLoader` pattern); validates: both NPC IDs known and registered,
   no self-pairs, trust/affection within 0–100, no duplicate pairs. Rejects
   bad data with clear exceptions.
3. Query API: `Trust(from, to)`, `Affection(from, to)`; unknown pair → define
   and document a sensible default (e.g. 50/50 "stranger") — this is a small
   judgment call, record it.
4. Add validated internal capture/restore (snapshot + atomic install) so P2-12
   can persist it without touching your code.
5. Deterministic iteration order (ordinal NPC ID order).

## Tests required
- Mira's 4 relationships load with exact trust/affection/reason values.
- Directed: A→B can differ from B→A.
- Unknown NPC ID, self-pair, out-of-range value, duplicate pair → rejected.
- Capture/restore round-trips exactly.
- Full suite green, Debug + Release.
