# P7-01: Aging

**Role:** Agents (NPC behaviour) agent
**Branch:** task/P7-01-aging
**Depends on:** P6-04

## Goal
Implement NPC aging: age advances yearly, life stages (child/adult/elder), death from old age (deterministic, not random).

## Context
Phase 7 is "Reincarnation and generations". This task builds the aging foundation. P7-02 will add families. P7-03 will add inheritance.

## You must not edit
- Anything outside the folders above. Content/ is approved.

## Requirements
1. **Age advancement**: Each NPC has an age (years). On their birthday (once per year, on a fixed day), age += 1.
   - Birthdays are deterministic: use the NPC's ID hash to pick a day of year (1-365).
2. **Life stages**:
   - Child: age 0-14
   - Adult: age 15-59
   - Elder: age 60+
   - Add `LifeStage` property to NpcState (computed from age).
3. **Death from old age**: Elders have an increasing chance of dying each year.
   - Age 60-69: 5% per year
   - Age 70-79: 15% per year
   - Age 80+: 40% per year
   - Use seeded RNG for the death roll (once per year, on birthday).
   - When an NPC dies: mark as deceased (do not remove from registry yet; P7-03 needs the body for inheritance). Add `IsDeceased` flag.
   - Record a truth event (Death).
4. **AgingSystem** (IWorldSystem): Runs daily; checks if any NPC has a birthday today; advances age, rolls for death if elder.
5. **Children**: NPCs start as children (age 0) if born in the simulation (P7-02 will add births). For now, existing NPCs have their Content ages.
6. **Deterministic**: Birthday day and death rolls use seeded RNG (or deterministic hash for birthdays).

## Tests required
- `AgeAdvancesYearly`: NPC age 30; run 365 days; verify age 31.
- `LifeStages`: Verify child (10), adult (30), elder (65) stages.
- `EldersMayDie`: Create many 85-year-olds; run a year; verify some die (use seed that triggers deaths).
- `DeathIsRecorded`: NPC dies; verify Death truth event exists, IsDeceased is true.
- `BirthdaysAreDeterministic`: Same NPC ID always has same birthday.
