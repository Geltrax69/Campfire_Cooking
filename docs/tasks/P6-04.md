# P6-04: Phase 6 acceptance (multi-village simulation)

**Role:** Test & Scenario agent
**Branch:** task/P6-04-acceptance
**Depends on:** P6-01, P6-02, P6-03

## Goal
Prove Phase 6 works end-to-end: a 30-day multi-village simulation where trade flows between villages, news spreads, and all state survives save/load.

## Context
Phase 6 is "Expanded world". P6-01 built village LOD. P6-02 built trade routes. P6-03 built news travel. This task:
1. Wires village state (VillageRegistry, TradeRoutes, NewsStore) into save/load persistence (format v6, or extend v5)
2. Runs a 30-day multi-village acceptance simulation
3. Produces a readable log

## Requirements
1. **Persistence wiring**: Extend the save format to include:
   - `VillageRegistry` (all villages + drift cursor, use Capture()/Restore())
   - Trade routes (if they have state; if static, document)
   - `NewsStore` (in-transit, arrived, opinions; use Capture()/Restore())
   - Bump format version (5 → 6) and ensure v5/v4/v3/v2/v1 load with village defaults.
2. **30-day acceptance scenario** (`SimulationTests/Scenarios/Phase6MultiVillageAcceptanceTests.cs`):
   - Set up: Millbrook (full) + King's Rest + Oakhollow (abstract).
   - Simulate 30 days:
     - Each day: run village drift, trade (merchants travel), news (publish/deliver).
     - Trigger an event in Millbrook (e.g., wolf attack) on day 10; verify news reaches King's Rest.
     - Verify trade happens (merchant buys/sells, wealth changes).
   - Verify:
     - News from Millbrook arrives in King's Rest after travel time.
     - Trade goods flow (wealth changes in villages).
     - No exceptions, all villages in valid state.
   - Deterministic (fixed seed).
3. **Readable log**: Write to `SimulationTests/Scenarios/Phase6_Acceptance_Log.md`:
   - Day-by-day or week-by-week: village stats, trade activity, news deliveries.
   - Final: village states, trade summary, news summary.
4. **Save/load round-trip**: Save at day 15, load, continue to day 30. Verify final state matches uninterrupted run.
