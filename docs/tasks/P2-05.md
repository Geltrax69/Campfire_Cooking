# P2-05: Goods expansion (general store stocks real goods)

**Role:** Economy
**Branch:** task/P2-05-goods
**Depends on:** P1-21

## Goal
Tilda Bray's general store sells real goods — salt, cloth, lamp oil, nails,
rope, basic tools — with stock and prices, so villagers can buy more than apples.

## Context
`Content/items/items.json` already defines `item_salt`, `item_cloth_local`,
`item_cloth_imported`, `item_lamp_oil`, `item_nails`, `item_rope`,
`item_tool_basic` (56 items total). The shop system (P1-07) and `ShopRegistry`
(P1-21d) exist. This task stocks the general store (`loc_general_store`) and
proves multi-good trade works. Restocking via traveling merchants comes in
P2-08; here the store starts stocked and sells down.

## You may edit
- `Packages/com.geltrax.livingworld.simulation/Runtime/Economy/`
- `SimulationTests/Economy/`

## You must not edit
- `Content/` (approved data — human owns). If an item you need lacks a sane
  price, use the existing `basePriceCopper` from items.json and note it; do
  not invent economy design.

## Requirements
1. A world-build step (or scenario helper) stocks the general store with the
   seven goods: starting quantities and unit prices from a small, documented
   table in code (quantities: enough for weeks of demand, not infinite —
   justify each in a comment; prices: `basePriceCopper` from items.json unless
   the design doc says otherwise).
2. Purchases of each good work through the existing `Shop` buy flow
   (full/partial/failed), moving stock and copper correctly.
3. NPC daily decisions may buy these goods when needs/schedule call for them
   ONLY if the existing decision system already supports it — do not build
   new decision logic here (that's P2-03 territory). If nothing buys them yet,
   the acceptance test (P2-11) will drive purchases; say so in your report.
4. New goods participate in save/load: they are shop stock under
   `WorldState.Shops`, which P1-21e/f already persist — add a test proving a
   general-store purchase survives save→load.

## Tests required
- Each of the seven goods can be bought; stock drops, copper moves, money conserved.
- Over-buy (want 7, have 2) behaves per the shop's existing rules.
- Save → load → the stock and prices are intact.
- Full suite green, Debug + Release.

## Done when
- [ ] Focused and full tests pass in Debug/Release
- [ ] No Unity/nondeterministic APIs, C# 9, no out-of-scope changes
- [ ] Results/open questions recorded (including whether NPCs buy these goods yet)
