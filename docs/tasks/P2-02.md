# P2-02: Relationship dynamics (interactions shift trust/affection)

**Role:** Knowledge
**Branch:** task/P2-02-rel-dynamics
**Depends on:** P2-01

## Goal
Relationships change through interaction by rule, not script: honest trade,
gifts, conversations and witnessed wrongs move trust/affection, which then
slowly decay toward their Content baselines.

## Context
P2-01 made the directed trust/affection pairs live state. Now they must
*move*. The design gives the reasons (e.g. Mira "suspects the boy takes
windfalls, can't prove it, half-fond anyway" — trust 40, affection 60).
Dynamics must be small, bounded, explainable rules. P2-03 will make behavior
read these values.

## You must not edit
- Anything else. Do not change how trades/purchases execute (Economy owns

## Requirements
1. A `RelationshipDynamics` system (or equivalent) that, each tick (or on
   event), applies bounded shifts from world events:
   - completed honest trade → small trust+ between buyer and seller;
   - gift given → affection+ (and small trust+);
   - conversation in tavern → tiny affection+ between participants;
   - witnessed theft/wrongdoing → trust− toward the perpetrator for witnesses
     (magnitude scales with existing relationship — betrayal by a trusted
     friend hurts more than by a stranger; document the formula);
   - failed promise / unpaid debt → trust−.
   Keep each shift small (±1..5) and clamp to 0–100. Every rule needs a
   one-line *reason* comment.
2. Slow decay: each in-game day, every shifted pair drifts a fraction back
   toward its Content baseline (the loaded value). Document the rate.
3. All shifts append a world event (kind `RelationshipShift` or similar:
   time, from, to, trustDelta, affectionDelta, reason) so perception,
   save/load and the log can see them.
4. Add validated internal capture/restore if you add any new mutable state
   beyond the P2-01 registry (the registry itself already has it).

## Tests required
- Honest trade raises buyer↔seller trust by the documented amount.
- Witnessed theft drops witness→thief trust; bigger drop when prior trust was high.
- Gift raises affection.
- Clamp: trust never exceeds 100 / drops below 0.
- Decay: after N days without interaction, values move back toward baseline.
- A `RelationshipShift` event is logged for each shift.
- Full suite green, Debug + Release.
