# P1-15: Conversations and traceable rumors

**Role:** Knowledge
**Branch:** task/P1-15-rumors
**Depends on:** P1-12

## Goal
Allow co-present NPCs to pass selected beliefs through conversations with a trust
filter, confidence loss, optional seeded distortion, and a traceable source chain.

## Context
The witness branch of the Apple Test requires information to travel through believable
meetings. A listener learns only what a speaker believes, never hidden world truth.

## You may edit
- `Packages/com.geltrax.livingworld.simulation/Runtime/Knowledge/`
- `SimulationTests/Knowledge/`

## You must not edit
- Anything outside the folders above. If another area's API is insufficient, stop and report it.

## Requirements
1. Use immutable caller-supplied conversation participants/context; do not inspect global schedules or locations.
2. Select from the speaker's own beliefs in stable claim order using caller-supplied salience/eligibility policy.
3. Calculate listener confidence from explicit caller-supplied trust/plausibility/tuning; reject zero confidence.
4. Support a seeded mutation roll using only `WorldState.Rng`; the actual structured-claim transformation must be
   supplied through an explicit distortion policy because approved design does not define an exact transformation.
5. Store accepted rumors as `ToldBy(speaker)`, preserve the original truth-event reference when present,
   and append an ordered, nonrepeating source chain.
6. Prevent rumor loops and self-conversations; never read or add facts absent from the speaker belief/policy result.
7. Append one `Conversation` truth event for an attempted eligible exchange, without implying bystanders heard it.
8. Keep deterministic ordering, C# 9 compatibility and no Unity references.

## Tests required
- Trusted listener receives a lower-confidence belief with speaker and complete source chain.
- Distrusted listener rejects it; another NPC not in the conversation learns nothing.
- Fixed seed reproduces mutation/no-mutation and selected belief exactly.
- A supplied distortion can make a claim vaguer but cannot add an unprovided actor/fact.
- Cyclic source chains and repeated processing do not amplify confidence or loop indefinitely.
