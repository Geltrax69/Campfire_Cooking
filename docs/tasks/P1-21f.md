# P1-21f: Load world state from JSON + determinism proof

**Role:** Persistence
**Branch:** task/P1-21f-load
**Depends on:** P1-21e (saver + documented schema)

## Goal
Rebuild a `WorldState` from a P1-21e save document and prove the roadmap's P1-21
pass condition: **run(1000) == save→load→run(1000)**.

## Context
The saver (P1-21e) writes versioned JSON and documents its schema. The restore
contracts (P1-21a/b/c) rebuild each area. The loader wires them together:
fresh world → load approved `Content/` definitions by ID → restore every area.

- `Packages/com.geltrax.livingworld.simulation/Runtime/Persistence/`
- `SimulationTests/Persistence/`

## You must not edit
- Anything else. If the schema is missing something the loader needs, report it
  (do not redesign the saver yourself).

## Loader notes (from P1-21d)
- `WorldState.Clock` has an `internal set` — Persistence (same assembly) can set it directly.
- `SimRng` state: construct the fresh world with `new WorldState(savedRngState, savedClock)` —
  `SimRng(ulong seed)` sets `State = seed`, identical to `FromState`, so the RNG stream
  resumes exactly. No Runtime addition needed.
- `AppleScenarioState` (buyer/meeting/theft scheduling progress) deliberately stays
  harness-owned, not in `WorldState`. The determinism test should drive the scenario
  the same way on both sides of the save/load (same driver code), so this is fine —
  but do NOT try to persist it.

## Requirements
1. `WorldLoader` (name your choice): JSON string → fully restored `WorldState`.
   Load immutable definitions from approved `Content/` by ID first, then restore
   each area through the P1-21a/b/c contracts (event log, command queue,
   NPCs, memories, perception cursor) plus the P1-21d world-state areas
   (shops, belongings, production/restock/price states, reputation, travel,
   clock, RNG).
2. **Atomic validation**: malformed JSON, unknown `formatVersion`, unknown
   definition/item/NPC IDs, or inconsistent values are rejected with a clear
   exception BEFORE any world state is built (never a half-built world).
3. **Determinism proof** (the P1-21 acceptance test): build the Apple Test
   village with a fixed seed, run 1000 ticks → canonical snapshot A. Rebuild,
   run 400 ticks, save, load into a fresh world, run 600 more → snapshot B.
   Assert A == B (compare via a canonical state digest: clock, RNG state,
   event-log tail, NPC needs, shop stock/prices, belief/memory counts — or the
   existing story/snapshot writer if it covers enough).
4. Round-trip stability: save → load → save yields byte-identical JSON.

## Tests required
- The determinism test above (this is the P1-21 pass condition).
- Round-trip byte stability.
- Rejection tests: corrupt JSON, wrong version, unknown IDs, contradictory
  values — each throws, none leaves a half-built world.
- Full suite still green, Debug + Release.
