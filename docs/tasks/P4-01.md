# P4-01: Animal state

**Role:** Agents (NPC behaviour) agent
**Branch:** task/P4-01-animal-state
**Depends on:** P3-04

## Goal
Implement animal state from docs/design/ANIMALS.md: 5 species with populations, individual animals with trust 0-100, and per-location animal stores.

## Context
Phase 4 is "Animal ecosystem (wolves, deer, livestock) and taming through trust". This task builds the state foundation. P4-02 will add ecosystem dynamics (predation, breeding). P4-03 will add taming mechanics.

## Requirements
1. **Species definitions**: Load from `Content/animals/species.json`. Five species:
   - `species_chicken` (domestic, ~20 village-wide)
   - `species_pig` (domestic pigs + wild boars, same species)
   - `species_deer` (wild, ~40 in forest)
   - `species_wolf` (wild, pack of 5-7)
   - `species_brambleback` (wild, ~25 burrows)
   - Each has: id, name, habitat locations, diet, temperament, taming parameters (bond threshold, daily gains/losses).
2. **AnimalId**: Strongly-typed ID for individual animals (e.g., `animal_chicken_001`).
3. **AnimalState**: Per-animal:
   - Species ID, AnimalId
   - Location (where it lives/ranges)
   - Trust 0-100 (for taming; wild animals start at 0, domestic at 20-30)
   - Bonded owner (nullable NpcId/ActorId; null = wild/unbonded)
   - Age category (young/adult; for breeding)
   - Health (0-100, for predation/injury)
4. **AnimalStore**: Per-location or global collection:
   - `Get(animalId)`, `GetBySpecies(speciesId)`, `GetByLocation(locationId)`
   - `Add(animal)`, `Remove(animalId)` (for death/slaughter)
   - Population counts per species
   - `Capture()`/`Restore()` for Persistence (save/load-compatible)
5. **WorldState integration**: Add `AnimalStore` to WorldState (or as a new section). Must have public Capture/Restore.
6. **Initial populations**: Provide a factory method `CreateInitialPopulations()` that creates the starting animals per the design (20 chickens, 2 sows + piglets, 40 deer, 6 wolves, 25 bramblebacks) at their habitat locations.
7. **Deterministic**: No randomness in state creation (positions/names can be ordinal).

## Tests required
- `SpeciesLoadFromContent`: All 5 species load with correct IDs and taming parameters.
- `InitialPopulationsMatchDesign`: CreateInitialPopulations creates ~20 chickens, 40 deer, etc.
- `TrustBounds`: Trust cannot go below 0 or above 100.
- `AnimalStoreQueries`: GetBySpecies, GetByLocation return correct animals.
- `CaptureRestoreRoundTrip`: AnimalStore survives save/load.
